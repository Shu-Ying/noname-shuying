# 梦三卡牌稀有度

统一来源：各牌组 metadata 的 `rarity`，汇总到 `card-definitions.js`。`cards/rarity-data.js` 的 `cardRarities` 自动派生，卡面继续按真实牌名读取。

| 值 | 名称 | 参考视觉 |
| --- | --- | --- |
| common | 普通 | 银灰名称栏与框线 |
| uncommon | 罕见 | 青蓝名称栏与框线 |
| rare | 稀有 | 金黄名称栏与框线 |
| event | 事件 | 绿色名称栏与框线 |
| ancient | 先古之民 | 紫黑卡底与银色框线 |

遗漏或 `null` 默认普通；未接入注册表的 noname 原生牌也统一按普通显示。已明确填写的等级继续优先。刘备94张原版牌与1张巨石衍生牌现已填写；后续职业填写各自 metadata，无色牌填写 `packs/colorless/data.js`。
`basic`（初始）与 `token`（衍生）沿用普通的中性配色，但级别名称独立。`status/curse/quest` 提供状态、诅咒、任务名称，暂时保留已有卡面视觉。完整字段说明见 `CLASSIFICATION.md`。
配置统一用于手牌、持有牌、图鉴、战斗牌堆和卡牌奖励。详情和无障碍信息提供级别名称，不只依赖颜色。
事件与先古之民是来源类别，不是概率上的高低排序。暂不修改奖励掉率、费用、效果、升级规则或立绘。
手牌装饰使用空文本节点、data 属性和 CSS，保留感染动态边框、原生 card::after、选择提示与点击区。
