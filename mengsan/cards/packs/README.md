# 角色牌组

当前铁甲战士主表 94 张：新增 67 张、沿用 27 张；另有衍生牌【巨石】。专属牌归刘备，基础打击/痛击分别沿用杀/重杀。所有正常获得入口沿用 `canAcquireCard` 的角色检查。杀、重杀保留原有通用牌归属，并纳入刘备的随机生成牌池。旧存档的独立打击/痛击转换为杀/重杀，保留实例ID、强化和词缀；待结算候选保留原ID以避免冲突。

| 目录/文件 | 职责 |
| --- | --- |
| `liubei/index.js` | `LiuBeiCardPack`，组合刘备牌组运行时 |
| `liubei/data.js`、`advanced-data.js` | 新增 67 张及巨石的详情页数值 |
| `liubei/metadata.js`、`names.js` | 刘备专属牌的归属、费用、强化、原有牌名和基础牌映射 |
| `liubei/legacy.js` | 沿用的 25 张牌和兼容重杀定义 |
| `liubei/runtime.js`、`advanced.js` | 效果与本场持续状态 |
| `liubei/rewards.js` | 本次新增牌的永久奖励条目 |
| `colorless/` | `ColorlessCardPack`，所有角色共享，当前数据、效果和奖励为空 |
| `index.js` | 汇总各牌组类，检查重复定义，转发公共事件 |
| `data.js`、`rewards.js` | 汇总各牌组的纯数据与奖励 |

未来加入曹操、孙权时各建目录和牌组类，在三个汇总入口登记；费用、强化和永久注册表读取汇总数据，`mode-cards.js` 只保留三国杀通用牌适配。原来的 `ironclad*.js` 导入路径保留兼容导出。

新增无色牌时：在 `colorless/data.js` 登记 `name/category/cost/base/upgraded`；在其牌组类返回实际的 `cards/translate/skills/names`，再补奖励条目。无色定义固定为 `owner:null, deck:"colorless"`，添柴的牌池会自动扩充。三国杀通用牌保留 `deck:"legacy"`，不会自动被算作无色牌。

个人牌堆、费用支付、消耗记录、临时免费用牌授权和抽牌入口属于共用机制。`ironclad-hooks.js` 目前是牌组向这些入口注册本场效果的轻量桥接模块，不导入引擎或牌数据；状态受当前战斗会话约束，结束即清理。

适配规则：添柴使用所有可正常生成的刘备牌与无色牌；巨石仅由原始力量生成，不进入永久奖励。多人效果按梦三存活角色处理，群情激愤向全部存活角色的个人弃牌堆加副本；肉盾作用于梦三友方阵营，采用详情页的双倍/减半数值。自动打出的牌沿用原生合法目标与牌效果。

本次仅做源码语法、引用和图片文件核对；实际对局与视觉验收由用户执行。

打击牌判断：杀对应基础打击，计入完美打击，并能被地狱狂徒自动打出；重杀对应痛击，不属于打击牌。
