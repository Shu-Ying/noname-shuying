# 卡牌类型与稀有度接入

`card-definitions.js` 是永久牌的唯一分类注册表。`cardType` 表示攻击、技能、能力等玩法类型，`rarity` 表示原版稀有度；无名引擎的 `type` 继续用于基本牌、锦囊、装备及状态的响应与结算。

| 字段 | 可用值 |
| --- | --- |
| cardType | attack / skill / power / status / curse / quest / equipment |
| rarity | basic / common / uncommon / rare / event / ancient / token / status / curse / quest |

未确认的类型允许 `null`。稀有度未填写或为 `null` 时统一默认 `common`（普通），未接入注册表的 noname 原生牌在卡面读取时也默认普通。现有三国通用牌已按实际用途适配类型，除杀、重杀对应打击、痛击保留初始级别外，其余未填写级别的通用牌默认普通；明确填写的等级继续优先。

刘备当前94张原版牌与1张巨石衍生牌，分类存放于 `packs/liubei/traits.js`。来源记录在项目根目录 `sts2-card-capture-20261003/generation/卡牌分类快照.json`。本地拆包优先用于匹配，已发现的版本差异以Wiki正式版为准：放血普通，挑衅罕见，主宰罕见，残酷稀有；擒拿以Wiki卡牌导航补全为罕见攻击牌。巨石按 `GiantRock` 标记为衍生攻击牌；没有采用名称相似的 `RollingBoulder`。

后续曹操、孙权等牌组在各自 metadata 的条目中填写这两个字段；无色牌在 `packs/colorless/data.js` 填写相同字段，纯数据汇总入口自动传递。登记值会校验，并同步给模式卡定义、创建的牌组数据、个人牌堆实体的存储数据。旧存档进入个人牌堆时重新按牌名补全，外部传入的分类不能覆盖注册表。

攻击判定、攻击牌生成、腐化和双持读取实际类型；对未配置的旧牌保留原有兼容判断。图鉴与持有牌详情显示同一分类；图鉴支持类型与稀有度联合筛选。

卡面稀有度入口 `rarity-data.js` 自动从注册表派生，继续使用 `getCardRarity/applyCardRarity`。初始和衍生沿用中性配色，并保留各自级别名称；状态、诅咒、任务目前只输出级别，保留已有卡面视觉。

本次保留现有奖励随机概率、事件牌获取途径、添柴的全牌组随机规则，不依据稀有度新增排除规则或权重。巨石继续仅在战斗中生成。

核对边界：只做源码语法、字段覆盖和文件引用核对，不构成实机验收。
