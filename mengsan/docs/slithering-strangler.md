# 蛇行扼杀者

资料：https://sts2.huijiwiki.com/wiki/蛇行扼杀者 ，紧缠：https://sts2.huijiwiki.com/wiki/紧缠

实现普通数值，不将进阶8+/9+数值混入普通关卡。生命53～55，资料默认54；仅实际入场从征程随机源抽取生命。无初始能力。

- 缠身：给予所有存活敌对角色3层紧缠。
- 缠身后等权重随机重击（7伤害、结算攻击后获得5护甲）或甩动（12伤害）；攻击后必定回到缠身。
- 紧缠可叠加，每个受缠角色自己的结束阶段开始时受到层数对应的非攻击伤害，原生护甲正常抵扣；不自动衰减，不受力量、虚弱和易伤的攻击修正。
- 按施加来源独立记录。同名多怪不会互相覆盖；来源死亡立即移除其贡献，复活不会恢复旧紧缠；受缠角色死亡及战斗资源释放时清除。本状态只保存在本场战斗，不写入征程存档。
- 预测行动每次耗1费用；费用不足则跳过效果并推进一次。击晕advance推进一次、retry保留原意图，随机攻击不会因重复刷新或retry重新抽取。保留原生出牌阶段。

已注册角色、怪物类型、普通关卡随机列表、行动执行器、意图UI、击晕与力量适配。角色专属首关及后续章节不改。

立绘：网页透明原图作为身份参考，飞蝇菌子密林立绘作为画风参考，经内置图像生成工具二次绘制为独立3:4不透明背景图片。完整提示词位于同一验证目录的strangler-prompts.json。

验证仅为隔离状态机/实际源码执行检查，不代表用户实机或十周年UI验收。
