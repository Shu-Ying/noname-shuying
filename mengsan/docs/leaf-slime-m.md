# 树叶史莱姆（中）

来源：https://sts2.huijiwiki.com/wiki/树叶史莱姆（中）

普通配置：生命32～35（展示默认34）；无初始能力。第1回合黏糊射击，向敌对角色个人弃牌堆加入2张黏液；随后团块射击（8点攻击伤害）与黏糊射击严格交替。
进阶参考：8+生命33～36，9+攻击9；当前未混入普通配置。

怪物ID：`mengsan_leaf_slime_m_shuying`，加入第一幕普通怪物池；首层专属开局及后续幕不变。每次意图耗1费用，保留原生用牌阶段；眩晕retry保留意图、advance进入下一行动。复用已有黏液卡（耗1费用，抽1张，消耗），不进入永久卡组和奖励注册表。中型状态与小型独立，后者仍等权随机冲撞/黏液。
