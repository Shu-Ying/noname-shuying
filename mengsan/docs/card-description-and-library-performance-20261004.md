# 卡牌介绍与图鉴滚动优化（2026-10-04）

根据 66.png 与本次要求修正此前“介绍包含当前费用”的约定。

## 描述

- 卡牌介绍去掉“梦三：”前缀，不再重复普通主动使用费用或普通响应免耗费用。
- 费用角标与图鉴费用筛选继续保留，费用支付和卡牌效果不变。
- X 费用保留消耗规则；X 表示本次消耗的剩余费用。获能、减费、临时免费及濒死救援等特殊机制仍需说明。
- 已强化卡牌继续显示当前效果数值，不追加升级前后对比。
- 模式注册的动态介绍与静态翻译统一清理；图鉴、持有牌、奖励卡片也使用同一清理入口。

## 图鉴与持有牌

- 以原有卡牌大小与网格排列计算全部行，保留完整滚动高度。
- 只挂载可见行与上下各两行预览；继续显示的卡牌复用，离开范围后回收。
- 滚动监听不阻塞原生滚动，并合并到每帧更新；关闭弹窗时取消更新并移除监听。
- 图鉴介绍与搜索文本按弹窗缓存；持有牌介绍按实例缓存。搜索输入等待 140 毫秒后更新，刷新牌堆时清理旧缓存。
- 图片异步解码，卡牌绘制范围隔离；避免滚动时重新解析全部介绍和重建全部图片。
- 详情返回保留原滚动位置；窗口尺寸变化重算行列；方向键与 Tab 可访问尚未挂载的后续卡牌。
- 不修改牌组、存档或抽牌顺序。战斗中分区牌堆保留原有顺序展示。

## 验收范围

仅进行源码、语法与差异核对，未运行行为测试或实机性能测试。实机应核对：暴走等普通牌介绍仅显示效果；旋风斩、倾泻等 X 牌有明确消耗说明；大量卡牌时滚动、筛选、返回详情、缩放与键盘连续浏览正常。
