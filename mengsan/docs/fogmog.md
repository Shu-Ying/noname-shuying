# 雾菇与利齿之眼

来源：[雾菇](https://sts2.huijiwiki.com/wiki/雾菇)、[晕眩](https://sts2.huijiwiki.com/wiki/晕眩)，读取日期2026-10-02。
网页立绘保留原始字节；Wiki标注CC BY-NC-SA 4.0。晕眩卡图复用项目现有STS2资源。

- 默认使用网页普通难度：雾菇74生命；重击8伤害并在结算后获得1力量；头槌14伤害。
- 第一自身行动使用虚幻孢子，召唤一个6生命的利齿之眼。之后先重击；一次重击后40%再重击、60%头槌；两次连续重击后必定头槌；头槌后必定重击。
- 利齿之眼只发动牵制：向敌对角色的个人弃牌堆加入3张晕眩。无个人牌堆的剧情援军不污染公共牌堆。
- 晕眩仅存在于本场战斗，不能使用或打出，弃牌阶段开始按既有虚无机制移除；不进入永久牌组或奖励池，没有费用角标。
- 利齿之眼死亡后，在下一次主角回合开始前满血复活，复用原席位；雾菇死亡后不再复活或行动，爪牙不阻止胜利。
- 第一关普通遭遇池增加雾菇；利齿之眼不单独进入遭遇池。其他关卡和刘备专属开场不变。
- 沿用梦三行动技能消耗1费用、雾菇随后照常出牌的既有规则；爪牙不额外抽牌或出牌。本次未新增STS2进阶难度开关。
