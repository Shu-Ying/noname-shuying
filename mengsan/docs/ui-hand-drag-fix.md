# 梦三手牌：41、42 图交互修正

本次基线是用户已应用的扇形手牌版本，修改限于 `ui/hand/`，不改十周年源码或设置。

- `showAim()` 将鼠标及卡牌的视口坐标，经 SVG `getScreenCTM().inverse()` 换算到 SVG 局部坐标；兼容 body zoom、父层缩放与平移，不重复套用 documentZoom。
- 自动单目标/无目标拖动期间，临时隐藏 `ui.control`、`ui.confirm` 和当前事件的 `endButton`。取消、松手、换事件及退出恢复；多目标维持原确认按钮。
- 合法自动提交时，沿原生鼠标提交流程先关闭旧确认及结束控件，再调用 `ui.click.ok()`。关闭动画中的旧控件不再残留显示；不关闭下一次新创建的控件。
- 新挂载标记将阶段图片隐藏范围限制在梦三手牌生命周期。仅匹配十周年 `lbtn/tips/` 的阶段图片，不隐藏响应提示图片。
- 短点击、复杂/技能/响应选择仍走原生路径；自定义确认替换的事件不接管。

验证是隔离浏览器测试，不等同于所有 UI 扩展组合及实际游戏验收。应用脚本直接写入对应文件，不生成安装目录备份；交付修正副本与安装状态须区分。
