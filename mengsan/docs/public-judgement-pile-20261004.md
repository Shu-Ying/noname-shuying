# 判定使用公共牌堆（2026-10-04）

本说明补充个人牌堆规则，以当前源码为准。

- 玩家摸牌、弃牌、个人牌堆洗牌继续使用个人抽牌堆与个人弃牌堆。
- 普通判定从公共牌堆取判定牌，公共牌堆不足时沿用原生公共洗牌流程，不消耗个人牌堆或触发个人牌堆不足失败。
- 创建判定事件时，默认判定牌结算位置使用公共弃牌堆。判定、判定回调和对应的处理区清理均使用公共节点，避免公共判定牌被个人弃牌堆收录。
- 判定中触发的独立摸牌或弃牌事件仍按其所属角色处理，不因父事件是判定而被改为公共摸牌或弃牌。
- 原生改判、获取判定牌及明确指定结算位置的技能保持原有处理；玩家自己的改判牌仍由个人牌堆的归属回收逻辑处理。
- 接管只作用于梦三战斗会话，结束后恢复原有牌堆访问和角色判定方法，不修改全局引擎文件。
