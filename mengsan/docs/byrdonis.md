# 多尼斯异鸟 BYRDONIS

2026-10-03读取：https://sts2.huijiwiki.com/wiki/多尼斯异鸟
密林精英，注册mengsan_byrdonis_shuying，加入act1Map.eliteEnemies，不加入普通池。现有精英保留。
普通生命81~84，每次实际敌方入场使用征程随机源均匀抽取；资料默认82不消耗随机数，显式hp优先。
初始领地意识1层；自身phaseAfter获得层数对应的力量，不是意图攻击后立刻获得。击晕或费用不足仍在活着的回合结束时触发。非自身回合、死亡或会话结束不结算。
行动SVG：开始→俯冲→啄击→俯冲，严格交替，无随机决策。网页表格称俯冲为“飞扑(Swoop)”，为同一行动。
俯冲17基础攻击伤害；啄击3基础攻击伤害×3，每段受力量/虚弱/易伤/缩小修正。无其他效果，正常前三回合17、4×3、19；力量在各回合结束后变为1、2、3。
进阶只记录不混入当前普通数值：A8生命90，A9俯冲19、啄击4×3。
使用梦三精英原生抽2、手牌上限5、费用3和精英牌堆。意图消耗1费用，原生出牌阶段保留；原生牌也获得既有力量修正，脚本意图不重复加力量。
费用不足跳过并推进；击晕retry保留招式、advance推进；眩晕恢复不移除领地意识。多只实例独立，不因重复规划、席位或死亡恢复重新抽生命。
循环、领地意识和力量随战斗会话清理；旧会话清理不能误删新会话的状态。
