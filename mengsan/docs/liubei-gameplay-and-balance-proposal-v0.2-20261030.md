# 梦三与刘备玩法调整方案 V0.2：敌人、意图循环与 Boss 联合平衡

- 日期：2026-10-30
- 状态：策划提案；建议参数尚未实施，也未完成游戏内验证。
- 范围：当前第一章、刘备、关张助战、4种弱池遭遇、12种强池遭遇、3种精英与3种 Boss 遭遇，以及它们的随从。
- 前版：[V0.1](liubei-gameplay-and-balance-proposal-20261030.md)。本版与前版冲突时以本版建议为准，V0.1 保留作对照。
- 证据：当前本地源码。下文的逐轮数据是规则推算，不是自动对局胜率；没有以外部游戏原版的数值证明梦三平衡。

## 1. 对 V0.1 的修正

V0.1 没有充分考虑怪物，不能直接作为平衡改动清单执行。它主要讨论玩家、助战和回复，遗漏了以下约束：

1. 怪物的攻击意图目前通常作用于全部存活敌对角色，刘备和助战各承受完整伤害；助战到场并不分摊刘备受到的意图伤害。
2. 意图通常只花1费用，之后仍能主动出牌。普通／精英／Boss 原有费用为2／3／4；图标上的意图伤害不等于整回合伤害。
3. 力量按攻击段数放大；增益招式后的原生攻击牌会立即享受新力量，不能把增益轮直接当作安全轮。
4. 血量之外，还有滑溜、护甲、回复、缩小、缓慢、伤口、感染、亡语和胜利条件。它们会改变击杀速度或实际生存空间。
5. 多敌人的循环会在某一轮叠出峰值，不能把单只怪物平均伤害相加后就判定合理。
6. V0.1 同时削减助战费用、摸牌、起手和攻击，缺少玩家能否承受后续怪物的依据；仁德换牌也不增加净手牌数量。

本版采用“先计算敌方整轮压力，再决定玩家可承担的防御成本和击杀时间”的方法。所有新规则均为策划建议，不能读成已经存在的机制。

### 2.2 应计算什么

以“刘备行动开始，到刘备下一次行动开始”为一轮，同时记录每个敌人实际执行的行动次数。下列简化表假设没有额外回合、击晕、提前死亡、反伤中断和异常状态；有这些效果时必须按实际行动重算。

- 每段攻击先计基础伤害与力量，再计虚弱、缩小，之后计目标易伤等修正。虚弱与缩小分别向下取整，易伤向上取整，不能先把所有段数合并再取整。
- 基础攻击修正示例：`每段 = ceil(floor((基础伤害 + 力量) × 0.75) × 1.5)`，仅适用于同时有虚弱和易伤、没有其他修正的情况。
- 一轮总压力 = 全部实际命中的意图伤害 + 实际命中的手牌攻击 + 感染／紧缠等额外伤害。
- 生命损失按事件顺序抵扣当时护甲；不把同一份护甲重复用于多个敌人。没有中途增减护甲等效果时，才可简化为 `max(0, 本轮可抵扣伤害合计 - 本轮护甲)`。
- 击杀所需时间同时取决于有效生命和实际输出。普通 `HP÷每轮输出` 只作估算；滑溜要数命中事件，雕像要数前置出牌，亡语要算下一批敌人。
- 单独记录刘备和助战生命。当前全部意图打全队时，增加队友会增加队伍总承伤，不会降低刘备承伤。

**例如多尼斯异鸟3段啄击，+3力量后为6×3＝18；若目标同时易伤，则9×3＝27。绝不能算成9＋3＝12。**

来源：[意图执行](../battle/intent-effects.js)、[意图伤害](../battle/intent-damage.js)。

## 5. V0.2 推荐采用的战斗规则

### 5.1 考虑过的两种路径

| 路径 | 做法 | 取舍 |
| --- | --- | --- |
| 保留自由出牌并降数值 | 保持当前全部意图打全队，敌人自由用剩余费用出牌，只降HP／伤害 | 改动较小，但意图仍不能解释整轮风险；需要大量对局才能约束峰值 |
| **意图明确目标，追加攻击也预告（本版推荐）** | 为招式区分单体／全体，收紧专属怪物的额外主动攻击，按完整预告调数值 | 需要调整执行与预告，换取可判断的防御窗口；保留有限的三国杀响应互动 |

推荐路径由本提案提出，尚不代表用户已批准实现。下列参数以推荐路径为前提；如果保留当前无限制混合出牌，不可直接套用后面的承伤结论。

### 5.2 意图目标与原生响应

1. 普通怪和精英的意图默认单体，固定预告指向刘备；墨宝旋风、藤蔓挥击、异蛙甩动、异鸟啄击明确为全体。负面状态默认只施加给本次目标。
2. Boss 招式按第8节逐招列出的目标执行。全体招式对每名友方结算完整伤害，不分摊；单体招式不暗中随机切到关张。
3. 来源或目标提前死亡时取消对应效果，不在行动时临时换人；现有“刘备阵亡则结束征程”的流程优先。
4. 脚本意图继续使用护甲、虚弱等机制应对，仍不能用闪直接抵消；预告中明确标注。实际追加的杀仍走闪、距离、装备等原生规则。
5. 敌人的闪、对决斗打出的杀和濒死救援等响应继续保留；它们仍可能延长实际击杀时间，必须纳入游戏内采样。

### 5.3 限制意图后的额外主动出牌

对有专属意图的敌人，取消“发动完意图后任意主动出牌”。只允许下述事先预告的追加杀；不再自由主动使用桃、酒、无中、决斗或过河。没有专属意图的首关士兵仍按原流程行动。

- 普通遭遇：整支敌队每轮最多追加1张杀。该轮只有在意图原始合计伤害加该杀伤害不超过16时可选；含力量、段数，暂不计目标易伤、护甲及玩家减益。该值是基础预算，实际易伤后的伤害必须另行显示。
- 精英遭遇：同口径上限20，整支敌队每轮最多追加1张杀。亡语生成的虫也共享额度。
- Boss：仅墨影“墨迹”轮允许追加1杀；仪式兽、同族小队不额外主动出牌，使用其完整意图循环提供压力。
- 只有本轮执行伤害意图的单位可以追加。整备、沉睡、苏醒、蓄力、召唤、单独施加负面状态和阶段击晕的单位不追加，形成真实准备窗口。
- 在刘备行动前从符合条件的敌人已有手牌中选择并锁定1张实体杀，按固定座次选首个合格单位；不得把敌人随后新摸到的牌临时追加。预告显示来源、目标、伤害和“可用闪响应”。
- 使用仍支付原费用并重新校验牌、距离、目标和战斗会话；牌被夺走、费用不足、单位被击晕时取消，不补抽、不替换、不补偿攻击。实际伤害按当时状态结算，预告随状态刷新。
- 群怪原始意图本身已超过16／20时，不通过暗中削伤压回预算，而是禁止追加，并按第7节调整组合和出场时机。

这项规则会改变敌人手牌的主动用途，也减少主动回血造成的额外有效生命；因此它与后面的HP调整需要分批验证。

## 9. 回合目标、牌组供给和跨关消耗

### 9.1 暂定的测试目标

“毛伤害”指实际扣血总量，尚未加回战中治疗及战后回复；它不同于意图原始伤害。

| 遭遇 | 暂定玩家回合数 | 对熟悉规则的代表牌组，刘备毛伤害目标 | 检查重点 |
| --- | --- | --- | --- |
| 首关 | 3—5 | 0—8 | 距离、坐骑、四回合剧情支援、提前胜利 |
| 弱池 | 3—5 | 4—10 | 不依赖稀有卡，单人也能通过 |
| 强池 | 4—6 | 8—16 | 组合优先击杀、应对状态牌 |
| 精英 | 5—8 | 14—24 | 有合理构筑后通过，失败能归因于战术或构筑缺口 |
| Boss | 7—10 | 20—32 | 约40以上生命进入时存在合理容错；各Boss按独立机制检验 |

这些区间是设计目标，不是对全部种子、全部操作或未成型牌组的保证。第4次普通胜利后也不能机械把敌人整体再加血来满足回合数。

### 9.2 同时满足防御和输出

不能分别证明“能打20伤害”和“能有10护甲”就认定该回合可行；必须使用同一手牌、同一费用和同一响应消耗验证。

- 3费用中用2张基础防御取得10护甲后，只剩1费用，基础杀只能打6且可能被闪。
- 每轮摸2、持续打出3张还要留闪，长期会缺牌。仁德给一摸一不增加刘备净手牌；助战也要花自己的费用用收到的牌。
- 12张初始牌库的空转周期不等于固定6轮：起手、无中、保留手牌、响应、弃牌、消耗、状态牌都会改变它。
- Boss前代表牌组至少分别验证：普通单体攻击构筑、易伤／力量构筑、消耗／多段构筑。不能只用一套极优稀有牌组来调全部Boss。
- 若多数代表牌组付出一费防御后，仍常常无法形成有效进攻，单独比较“刘备每回合摸3”实验；先冻结其他数值，避免一起加摸牌、加费用、减敌血。
- 昏眩、伤口、感染和缠结专门记录损失了多少有效出牌机会；不能都折成一个固定伤害系数。

### 9.3 续航与濒死

每场净变化按“入场生命＋实际战中治疗－毛伤害＋可生效的战后回复”计算，并受生命上限限制；阵亡时不能用战后6点逆转失败。

例如强池毛伤害12、没有战中治疗、战后实际回6，净耗6；连续4场约耗24，再考虑休息、商店和路线。休息由8提高至15的候选值应在这个背景下评估，而非仅与桃比较。

助战一旦濒死，当前救助取得途径尚不完整，必须测试缺席后能否继续推进。V0.2先用明确单体目标减少随机永久失去伙伴的风险；救助渠道作为后续独立设计项，不把未存在的免费复活计入生存预算。

## 10. 落地次序与验证要求

本次只交付方案。若后续实施，建议使用以下顺序，每阶段保留同种子对照，不把V0.2整包数值一次性落地。

1. **当前版本基线。** 记录实际入场HP、座次、起手、每次意图、力量、状态持续、主动牌、响应、护甲和净掉血；特别覆盖旧版墨影第3轮、同族第2／5／11轮、仪式兽转换和异蛙亡语。
2. **先改威胁可读性与规则。** 实施单体／全体目标、受限且可预告的追加杀，冻结HP与其他伤害；确认没有隐藏的额外主动攻击，并观察仅此改动降低多少压力。
3. **按遭遇逐个试建议HP与循环。** 先弱池，再强池组合，再精英，最后三个Boss。若第2阶段已经达到目标，相关降血／降伤可撤回，不机械执行全表。
4. **再试刘备与助战。** 确定到场、关张差异、仁德和初始牌组分别记录效果；先保留助战原资源，确认是否确实需要削弱。
5. **最后处理跨关续航及强构筑。** 单独试休息30%，再检查炽焰、扯碎及多段／消耗连锁，不用削核心牌补偿未处理的怪物问题。

建议首轮使用12组固定起始牌序／遭遇随机种子覆盖代表场景，不把同一随机种子的重复点击当独立样本。普通与精英各覆盖单独刘备、关羽、张飞；Boss另交叉3种代表牌组、至少2档入场生命（30／45）。无法一次完成时，先完成三个Boss及最高压群怪，不以少量样本发布精确胜率。

| 核对项 | 需要的记录／判据 |
| --- | --- |
| 循环正确 | 至少两圈；同族至少12轮包络；仪式兽分别覆盖早、正常、晚转换 |
| 伤害正确 | 按目标、按段、按当时力量及状态重算；示例中的53、44只是特定情景而非固定伤害 |
| 防御可行 | 同一手牌与费用同时满足防御和攻击；护甲不能跨自身回合误累计 |
| 群怪峰值 | 列出10种劫掠组合、三墨宝随机分支、双小啃兽错位、四史莱姆、飞蝇组合 |
| 实际减员 | 第一名敌人何时死、何时减少意图压力；不得只保留永远全员存活的模型 |
| 助战安全 | 被全体技能命中的轮次、是否在预告之外濒死、AI是否会用收到的牌 |
| 特殊机制 | 滑溜消耗、感染每张3伤害、亡语4虫、神官与雾菇胜利条件、击晕与昏眩区别 |
| 预告准确 | 显示目标与段数，额外杀单列；玩家改状态、夺牌或击杀后刷新；不给未锁定的新抽牌追加攻击 |
| 保存与兼容 | 旧存档现有牌组不强制重写；新数值作用范围明确；改过的规则说明同步 |

参数数据、手算／脚本推演、隔离行为检查和真实游戏对局是不同证据。只有真实对局才能验证敌方AI、响应选择、抽牌波动、战斗耗时和体验；本版没有宣称这些已经完成。
