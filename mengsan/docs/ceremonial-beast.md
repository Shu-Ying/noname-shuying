# 仪式兽 CEREMONIAL_BEAST
来源（2026-10-03）：https://sts2.huijiwiki.com/wiki/仪式兽；https://sts2.huijiwiki.com/wiki/横冲直撞；https://sts2.huijiwiki.com/wiki/昏眩
普通252生命，Boss，无初始能力。第一层bossEnemies追加仪式兽，保留墨影幻灵和同族小队及act1Map.boss旧兼容值。单单位Boss，不加入普通/精英池，不变更其他层及角色专属开局。
第一阶段：首行动跺地，获得150层横冲直撞；之后重复18伤害并自身力量+2。阶段二：野兽咆哮（昏眩）→踩踏15→碾碎17且自身力量+3→野兽咆哮。固定选择不消耗随机数；原生费用不足仍推进，击晕advance/retry沿用现有体系。
横冲直撞非护甲、不吸收伤害、不逐回合衰减；普通252最大生命的阈值150，明确覆盖最大生命按150/252等比取整。阶段一获得状态后必须发生damageEnd且伤害为正、角色存活、生命≤层数才触发；此前低血量不自动触发，loseHp不触发。移除横冲直撞、无论原力量正负重置0、跳过一次意图和原生出牌阶段；恢复后从野兽咆哮开始，不重复跺地。第二阶段不返回阶段一。
阶段切换中止当前意图后续目标/增益，避免反伤在横冲直撞途中击晕后仍获得力量。死亡、换场、会话结束同样中止后续效果。存活Boss仍阻止胜利。
昏眩是负面状态，不是晕眩卡；人工制品拦截一次施加。每位存活敌对角色独立至多主动使用1张实体/虚拟牌，零费牌同样计入，多目标仍算一张，失败/取消及响应不计数。useCard0在费用扣除前拒绝第二张强制使用，useCard1幂等计数，cardEnabled/cardEnabled2同步限制；自身回合结束/死亡/会话结束解除。梦三响应体系无STS对应，本实现不封锁闪/无懈响应。
Boss费用4，抽3，上限7；意图费用1，仍保留原生出牌。力量沿用每段攻击与原生攻击牌，不重复加算。永久牌组不变；独立不透明3:4密林立绘，基于网页原画二次绘制。
进阶A8 HP262，A9跺地160、横冲直撞20、踩踏17、碾碎19/+4，仅记录，不混入普通数值；多人没有自动新增血量缩放规则，仅跟随实际maxHp比例。
