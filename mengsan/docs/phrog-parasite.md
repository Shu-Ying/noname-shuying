# 异蛙寄生虫 / 扭动虫 / 感染

2026-10-03依据 https://sts2.huijiwiki.com/wiki/异蛙寄生虫 与 https://sts2.huijiwiki.com/wiki/感染。
普通数值：异蛙61~64生命，第一层精英池；固定感染(3张感染进个人弃牌)→甩动(4×4)循环。
寄生物4，死亡即召唤4只扭动虫。主网页正文以四只描述衍生怪，X未显式显示数值，交叉核对 https://slaythespire.wiki.gg/wiki/Slay_the_Spire_2:Phrog_Parasite 明确死亡生成4只。
扭动虫17~21生命，不单独进入精英关卡随机池；不是雾菇幻象，必须全部消灭才算胜利。
各组站位固定1~4，奇数位污秽啃咬6→扭动(1感染、2力量)循环，偶数位反向开局。
亡语生成的扭动虫完整首回合取消，不抽牌、不发动意图、不出原生牌、不耗费用，恢复后按原始奇偶站位起手。直接配置的扭动虫不强制跳过。
其余意图消耗1费用，保留梦三精英原生出牌；抽2，上限5，费用3。力量也作用于原生攻击。
死亡钩子原生引擎会await；等待4只入场后再继续伤害/卡牌，召唤期间阻止胜利结算。开战预留4个额外席位，计入死亡保留席位和所有后续剧情召唤，超过8总席位提前报错，不静默减少数量。
飞剑回旋镖原来逐击重新取存活敌人，后续击可以命中新生扭动虫。闪电霹雳改为先完整伤害再向当前存活敌人施加易伤，新生扭动虫也获得易伤，不重复吃刚结束的范围伤害。
感染不能被打出，无默认虚无；只生成到战斗个人弃牌，不进入永久奖励、商店或征程牌组。持有者结束出牌后的弃牌阶段开始时，每张仍在手牌的感染造成3点非攻击无来源伤害，走正常护甲及濒死救援；优先于虚无消耗，事件去重，死亡/换场中止后续结算。此时机沿用梦三现有虚无/弃牌实现，不是结束阶段之后重新读取空手牌。
