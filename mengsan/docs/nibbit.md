# 小啃兽 NIBBIT

来源：https://sts2.huijiwiki.com/wiki/小啃兽 （2026-10-02读取网页与SVG箭头）
普通怪物，密林；生命42～46，实际入场从征程随机源均匀抽取；资料默认44，不消耗随机数。无初始能力。
正常行动：顶撞12伤害 → 犹豫斩击6伤害并获得5格挡 → 哈气获得2力量 → 顶撞。
单只顶撞起手；双只按关卡units前后顺序固定为斩击/哈气起手，各自进入同一循环。开战时固定状态，不因同伴死亡或席位变化重置。
第一层普通池包括单只与双只遭遇；双只不占用永久牌堆/支援数据。超过两只的非标准自定义配置采用单只起手作为兼容回退，非Wiki定义。
意图消耗1费用、随后仍可使用原生卡牌；费用不足跳过本次动作并推进，眩晕支持retry/advance，遵循既有梦三适配。
力量影响脚本攻击与原生牌伤害；斩击先攻击后获格挡。既有伤害执行器继续处理虚弱、易伤及死亡/战斗结束。
