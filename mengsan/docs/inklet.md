## 配置

- ID `mengsan_inklet_shuying`，普通怪物；加入第一层普通战斗池。角色专属开局不变。
- 普通生命11~17；实际入场通过征程随机源等概率抽取，显式关卡生命优先，资料默认14。
- 网页描述成群且前/中/后起手不同，未指定固定数量；梦三适配为三只群体关卡，不声称三只是网页固定数量。
- 各只固定出生位置1/2/3，不因同伴死亡或支援插队重排。奇数位刺击3伤害起手；偶数位旋风2×3起手后刺击。
- 起手后进入循环：等概率选择锐利凝视10或旋风2×3 -> 刺击3 -> 等概率选择 -> 刺击。随机招不是每回合任意三选一。
- 各次意图仅生成一次；预览、重复计划、击晕retry不会重抽。每招1费用，无费用跳过并推进；击晕advance推进，retry保留。
- 沿用梦三怪物适配：意图攻击所有存活敌对阵营角色；保留个人牌堆；死亡或会话关闭及时停止多段攻击。
- 初始滑溜1：下次实际生命损失限制为1点；伤害完全被护甲抵挡不消耗；直接失去生命也适用。每段分别结算，第一段消耗后其他段正常。
- 梦三模式局部changeHp包装保留原生事件、护甲抵挡及消耗，滑溜层数仅在实际changeHp负向通知时减少，不改全局引擎。正向恢复、零伤害、关闭会话和其他怪物不受影响。斩杀直接死亡不拦截。
- 网页进阶8+生命12~18，9+刺击4、旋风3×3、凝视11，本次只记录，不混入普通配置。
