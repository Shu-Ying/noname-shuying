# 梦三界面缩放回归清单

无名杀原生 UI 底层以 `transform: scale()` 缩放，十周年 UI 以 `body.zoom` 缩放。检查通用界面时覆盖两条入口，并记录界面缩放、窗口尺寸、UI 版本和实际使用的风格。

## 实施方案

- 地图用实际渲染尺寸换算鼠标位移，保证地图和指针同速移动。窄小布局允许行军菜单和顶部栏在各自区域滚动。
- 选将和事件面板的高度随剩余空间调整，内容在面板内滚动，打开和关闭时恢复焦点也保持页面位置。
- 剧情将文本和分支选项放进同一滚动容器，跳过和菜单留在顶部。较高倍率下可滚动查看并点按选项。
- 牌库、牌堆、遗物、战斗状态、菜单确认和调试管理器沿用奖励与药水的原生对话框挂载方式，以可视窗口约束弹窗尺寸。打开、选择与关闭仍通过各自原有入口执行。
- 战场右侧的牌堆和遗物入口随可用高度调整。战斗状态平时放在头像上方，上方空间不足时移到头像侧面。

## 验收项

| 范围 | 操作与通过标准 |
| --- | --- |
| 选将、事件、商店、休息处 | 能看到主操作，点按后返回正确选择或退出。 |
| 地图和行军菜单 | 相同屏幕位移下，地图拖动与鼠标位移差不超过 2 CSS px。触屏能滚动，能点开菜单、查看行囊、返回和关闭，能选中可前往节点。 |
| 剧情 | 文本和分支选项可浏览，点按分支写入正确剧情状态，跳过和继续均可用。 |
| 奖励和战后结算 | 选牌、跳过和结算选项可到达，确认后继续流程。 |
| 牌库、牌堆、遗物、药水和战斗状态 | 能通过实际入口打开，弹窗在可视区域内，详情和关闭可点按。内容较长时能滚动。 |
| 菜单确认和调试管理器 | 对话框在可视区域内，所选操作返回正确结果，关闭后回到原界面。 |

## 浏览器复核

从术樱包根目录执行。脚本使用本地无名杀、十周年 UI、Playwright 和 Microsoft Edge。需要时将 `CODEX_NODE_MODULES` 指向包含 Playwright 的 `node_modules`，将 `HUD_ARTIFACTS` 指向已建立的截图目录。

```powershell
$env:UI_ZOOM_REVIEW = '1'
node mengsan/tools/test-battle-hud.cjs
```

自动回归覆盖 16 个界面与交互。以 812×375 横屏为基线，十周年 UI 检查 50%、65%、100%、150%、200%、300%，原生 UI 检查 150% 和 300%。两条缩放入口均检查界面打开后从 65% 切到 200%。另检查 420×360 窄屏、390×720 竖屏和 1280×720 桌面。

脚本通过渲染出的按钮执行代表性操作，检查界面边界、返回值和关闭结果。鼠标地图拖动单独检查像素误差。完整战斗 HUD 和出牌响应按[战斗回归清单](mengsan-battle-ui.md)复核。

## Android 实机复核

用 Android 客户端实际启用的十周年 UI 风格，在常用倍率和一个较高倍率下复核受影响的操作。优先确认触屏地图滚动、剧情分支点按、较长内容滑动和弹窗关闭。报告逐项标注通过、失败或未验。
