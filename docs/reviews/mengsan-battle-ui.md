# 梦三战斗 UI 回归清单

每次 review 核验下表各项。在报告中逐项写明通过、失败或未验，并记录证据对应的代码版本、皮肤、尺寸和缩放。涉及战斗 UI 的改动，附受影响场景的渲染截图。

| 场景 | 操作与通过标准 |
| --- | --- |
| 触屏拖牌与目标连线 | 从手牌拖出一张【杀】并移动到可选敌人。线起点贴在拖动牌上缘中央，终点跟随触点，两端误差各不超过 2 CSS px。取消手势后线立即消失。对合法目标松手后拖线立即消失，原生提交只触发一次。完整对局中再检查提交后的出牌特效能指向实际目标。 |
| 普通出牌布局与缩放 | 在主动出牌阶段检查手牌扇面、提示语和「确定／回合结束」按钮组。三者共用战场中线，误差不超过 2 CSS px。改变界面缩放后重新检查对齐和拖牌线两端。 |
| 出牌响应布局与按钮交互 | 敌人出【杀】，选择【闪】，观察场上出牌副本、响应文字与「确定／取消」两键的整体边界。三者从上到下共用战场中线，横向中心误差不超过 2 CSS px，牌面、提示、按钮和选中手牌之间有可见间距。确认和取消分别可点击，响应结束后场上的牌恢复原生位置。 |
| 弃牌时技能栏稳定 | 启用十周年 UI，进入需弃置两张手牌的场景并点选第一张。技能栏在重建的首帧起就不出现重复的药水按钮，普通技能仍可见，弃牌计数正常更新。 |
| 战斗药水槽与计数信息 | 持有药水进入战斗。药水槽位于左上区域，可贴近轮数、时间及牌堆数量控件，各自的可见区域互不重叠。点按药水可打开详情，并能在可用阶段正常使用。 |

## 浏览器回归

从无名游戏目录内的术樱包根目录执行。脚本使用本地引擎、十周年 UI 样式、Playwright 和 Microsoft Edge。Playwright 安装在其他目录时，可将 `CODEX_NODE_MODULES` 指向包含它的 `node_modules`。

```powershell
$env:HUD_REVIEW = '1'
node mengsan/tools/test-battle-hud.cjs
```

需要截图时，将 `HUD_ARTIFACTS` 指向已建立的临时目录。完整矩阵覆盖原生 UI、十周年 UI 的手杀、十周年和新杀风格，以及 1080×486、812×375、667×375，含非整数像素比。1080×486 使用无名杀「新版」布局，从 65% 缩放基线切换到 50%、85%、100% 和 120%，核验普通出牌位置和拖牌线。出牌后的默认及金龙连线均检查端点，完整金龙贴图需在客户端核验。

## Android 实机复核

在本轮改动对应的 Android 客户端启用十周年 UI，使用该客户端当前启用的皮肤复核各场景，并记录十周年 UI 版本和皮肤。拖牌时分别观察松手前的拖线和松手后的出牌特效。响应用两次事件分别检查确认和取消。弃牌时观察点牌瞬间，检查原生计数面板与药水槽能同时看清并各自操作。实机结果单独记录，实机不可用时写明未验。

涉及地图、剧情、奖励、牌库、遗物或其他公共弹窗时，一并使用[梦三界面缩放回归清单](mengsan-ui-zoom.md)。
