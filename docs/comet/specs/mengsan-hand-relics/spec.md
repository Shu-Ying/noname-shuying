# Battle hand relic list

梦三战斗手牌区左侧展示征程当前持有的遗物，复用既有图片、名称、描述和战斗状态。
列表条目为图片按钮；无图片或图片加载失败以名称替代，具有可访问名称。
现有遗物详情入口保留，不改变遗物业务行为。

### Scenario: 持有遗物展示
Acceptance: A1
进入战斗后左侧列表逐件展示持有遗物，图片与条目是一体，不另设文字列表。

### Scenario: 间距和溢出
Acceptance: A2
点击区域48×48px，条目间距至少8px，与手牌间隔至少12px。
窄屏和遗物较多时在列表内滚动，不覆盖手牌。

### Scenario: 长按描述
Acceptance: A3
持续按下500ms打开名称、描述和当前状态；提前松开、滚动、取消不会误打开。
浮层有关闭方式，位于可见屏幕内；键盘可打开并关闭详情。

### Scenario: 手牌兼容
Acceptance: A4
操作遗物不触发手牌选择、拖动或出牌，保留既有遗物详情入口和手牌交互。

### Scenario: 生命周期
Acceptance: A5
退出战斗或销毁会话清理列表、浮层、监听器及长按定时器，恢复布局空间；重新进入不重复挂载。
