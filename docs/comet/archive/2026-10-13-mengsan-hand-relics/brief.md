# Outcome

在梦三战斗手牌区最左侧常驻展示持有遗物的图片列表，长按条目显示遗物描述。

# Scope

复用现有持有遗物数据和图片资源，调整战斗遗物界面及必要的手牌布局。
图片本身就是列表条目，不增加独立文字列表。图片点击区域48×48 CSS像素，
条目间距至少8px，与手牌保留至少12px间隔。遗物过多时局部滚动。
长按500ms打开名称、描述和当前状态；滑动、取消和销毁会取消待触发长按。
描述浮层支持明确关闭，限制在屏幕可见范围内；提供键盘打开与关闭方式。
无图片或加载失败的遗物显示名称替代。保留现有详情弹窗入口作为补充。

# Non-goals

不修改遗物效果、获取规则、奖励池或存档，不改动其他游戏模式。
不处理其他变更、不发布版本、不自动提交或推送。

# Acceptance examples

- 战斗开始后，手牌区最左侧展示当前持有遗物；每件遗物仅有一个图片条目，缺图显示名称。
- 点击区域48×48px，条目间距至少8px，与手牌间隔至少12px；窄屏和遗物较多时可滚动且不重叠手牌。
- 长按500ms显示对应名称、描述和当前状态；提前松开、滑动或取消不误触；键盘也可打开并关闭详情。
- 遗物界面不触发手牌选择、拖动或出牌；既有手牌交互和遗物详情入口仍可用。
- 战斗结束或会话销毁后移除列表、浮层、监听器和定时器，恢复被占用的布局空间；再次进入不重复挂载。

# Decisions

用户选择当前目录，实现遗物图片列表与长按描述，并明确要求使用UI/UX技能。
UI/UX检索支持相邻触摸目标至少8px间距和按下反馈。

# Verification expectations

执行针对长按取消、数据展示和销毁清理的定向检查及语法检查；独立验证所有验收项。
真实引擎和设备上的触摸、缩放与手牌回归未执行时明确标记边界，不宣称实机通过。
